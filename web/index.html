      使用近传

      1. 让电脑和手机连上同一个 Wi‑Fi。
      2. 打开安卓端近传扫码。开启两端近传后，已绑定的手机会自动重连。
      3. 电脑能拖入文件发送。手机发来的文件会自动进入电脑收件箱。

      搜不到电脑时，检查 Windows 防火墙是否允许近传接收连接。网络隔离也可能阻止两台设备互访。

      关闭近传会结束本次文件传输。设备绑定和电脑收件箱会保存。
